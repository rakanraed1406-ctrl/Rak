# emotes — قائمة الحركات (أزرق + أحمر)

## الفحص (تلغيمات)
- **ما فيه باكدور ولا كود مخفي**: فحصت كل ملفات Lua و JS (حتى `dances.lua` 1.1MB): ما فيه تحميل كود من برا، ولا تشفير، ولا طلبات HTTP، ولا أوامر سيرفر.
- انشالت الإعلانات: ملفات `discord- sk1.txt` (3 ملفات) وتعليقات `Spark / discord.gg/sk1` من كل الملفات، واسم "Spark Emotes" صار "Emotes".
- ملاحظة: صور معاينة الحركات (GIF) تتحمّل من موقع خارجي `assets.cylexdev.com` — مو ضار، بس لو الموقع وقف ما تطلع صور المعاينة (الحركات نفسها تشتغل عادي).

## الأعطال اللي انحلت (المشيات وغيرها)
| المشكلة | وش كان يصير | الحل |
|---|---|---|
| المشيات والتعابير اسمها محفوظ بـ `value` والكود يقرأ `anim` | **المشية ما تتغير** ولا التعابير (من القائمة ومن `/walk`) | يقرأ الاثنين |
| حفظ المشية بعد الريلوق: الإعداد موجود بس ما له كود | ترجع المشية العادية | تنحفظ وترجع بعد الدخول / الإنعاش / ريستارت السكربت |
| البروب الثاني اسمه `prop2` والكود يقرأ `secondProp` | الدفتر يطلع بدون القلم مثلاً | يقرأ الاثنين |
| تغيير الحركة بدون إلغاء | البروبات تتكدّس باليد | تنشال القديمة قبل الجديدة |
| حركة ما تتكرر تخلص | البروب يبقى معلّق باليد | ينشال لحاله |
| حركة الخروج (`exit`) | ما تشتغل | تشتغل عند الإلغاء |
| الحركات المشتركة (مصافحة، حضن…) | ما تشتغل أبداً (الدعوة فاضية، والبيانات بشكل ما يفهمه) | كليك (أو كليك يمين) = دعوة لأقرب لاعب، هو يضغط **Y** يقبل / **M** يرفض، يوقف قدامك وكل واحد يسوي دوره. السيرفر يتحقق إن الدعوة حقيقية وإنكم قريبين |
| `/e` و `/emotemenu` و `playEmote` مسجلة مرتين (زر F6 و F4 متضاربين) | تضارب وتحذيرات | مرة وحدة — زر القائمة من `Config.OpenKey` |
| `/sequence` | ينادي كود مو موجود → error | انشال |
| الاختصارات (Shift + رقم) مكررة ونسخة منها تطلع error | error | نسخة وحدة شغالة |
| `IsPlayerCrouched` / `CrouchKeyPressed` / `AttemptCrouch` مو موجودة | ممكن توقف باقي الكونفق عند التشغيل | انكتبت (الانحناء + الزحف) |
| `isMenuOpened` ومنع عجلة الأسلحة والقائمة مفتوحة | ما يشتغلون | يشتغلون |
| حركة ناقصة ملفها من السيرفر | يعلق يحاول يحمّلها | رسالة "الحركة ناقصة" بدل التعليق |

## الألوان
- البرتقالي كله صار **أزرق** (`#3b9dfb`) — كلها متغيرات أعلى `html/assets/index.css`:
  `--accent-rgb` / `--accent-light` / `--accent-deep`.
- **الأحمر** اللون الثاني: نجمة المفضلة، زر إيقاف الحركة، ورفض الدعوة. (`--accent2`)

## الراديال منيو
- الحدث: `TriggerEvent('emotes:openMenu')` — صار **يفتح دايماً** (قبل كان يفتح/يقفل)، ويستنى لحظة لين يتقفل الراديال.
- الراديال عندك جاهز: `functionName = "emotes:openMenu"`, `functiontype = "client"` في `qb-radialmenu/config.lua`.
- فتح يدوي: `F6` (من `Config.OpenKey`) أو `/e` أو `/emotemenu`.

## السكربتات اللي يحتاجها
| السكربت | لازم؟ | ليش |
|---|---|---|
| **ox_lib** | **لازم** | مكتوب بالـ `fxmanifest` (`@ox_lib/init.lua`) — بدونه ما يشتغل |
| mt_core | لا (انحلت) | الإشعارات كانت تعتمد عليه وتطلع error بدونه. الحين تستخدم mt_core لو موجود، وإلا qb-core، وإلا ox_lib |
| mt_ambulance | لا (انحلت) | فحص الموت برفع اليدين كان يطلع error بدونه. الحين يفحص mt_ambulance لو موجود، وإلا بيانات qb-core (isdead / inlaststand) |
| **ملفات البروبات `stream/`** | للحركات اللي فيها أغراض إضافية | الـ `fxmanifest` يطلب ملفات `stream/*.ytyp` (bzzz, brummie, kaykaymods…) **وما هي موجودة بالـ zip**. الحركات العادية والرقصات تشتغل، بس حركات البروبات المخصصة ما يطلع غرضها. تجيبها من مجلد `stream` حق **rpemotes-reborn** وتحطها داخل `emotes/stream/` |

- السكربت يعلن نفسه كـ `rpemotes` / `dpemotes` / `scully_emotemenu` — **لا تشغّل معه** أي سكربت حركات ثاني من هذولي عشان ما يتعارضون.
- اسم المجلد لازم يبقى `emotes` (الـ exports تنادي `exports['emotes']`).
