# qb-input — Command Form (واجهة جديدة)

> انشالت إعلانات الدسكورد من الملفات ومن `README.md`. ما كان فيه كود مخفي بالسكربت.

## وش تغيّر
الـ export نفسه (`exports['qb-input']:ShowInput({...})`) وشكل البيانات اللي ترجع نفسه بالضبط — تغيّرت **الواجهة**:
- **نفس هوية الراديال منيو و qb-menu**: كحلي غامق + أزرق ملكي، نفس الخطوط، نفس الحركة، نفس متغيرات الألوان `--rm-*`.
- عنوان لكل خانة فوقها (مو بس placeholder)، والخانات الإجبارية عليها `*`.
- **radio** صار أزرار جنب بعض، **checkbox** صار سويتشات، **select** بستايل الواجهة، **color** يعرض كود اللون.
- لو خانة إجبارية فاضية: تصير حمراء وتهتز مع صوت رفض، وما ينرسل الفورم.
- زر **Cancel** جنب زر الإرسال.
- ما عاد يحتاج jQuery، وانحل خطأ كان يطلع بالكونسول عند ضغط Enter (`SubmitData is not defined`).
- الـ Lua ما يطلع error لو الفورم انقفل مرتين.

## الأداء
بدون `backdrop-filter` (المربع الأسود)، بدون طبقة تغطي الشاشة، بدون أنيميشن شغال على طول، الواجهة `display:none` وهي مقفلة، ومحرّك الصوت ينام بعد القفل.

## الأصوات
نفس أصوات العجلة و qb-menu: فتح، قفل، تنقّل بين الخانات، اختيار، إرسال، رفض.
التحكم فيها: `html/index.html` → `FormSfx.enabled` و `FormSfx.volume`.

## التحكم
`Enter` إرسال · `Tab` الخانة اللي بعدها · `Esc` قفل.

## الألوان
متغيرات `--cm-*` أعلى `html/styles/default.css` — نفس اللي في qb-menu و qb-ui.

## الألوان (تحديث)
صارت الواجهات الثلاث (`qb-menu` و `qb-input` و `qb-ui`) **أسود شفاف** مع **أزرق هادي** (رمادي مزرق) بدل الأزرق الملكي القوي، والنص أبيض ناعم.
المتغيرات `--cm-*` أعلى ملف الـ CSS — نفس القيم في الثلاثة. الشفافية بـ `rgba` عادي (بدون blur) عشان ما يرجع المربع الأسود وما يزيد الاستهلاك.
- الشفافية: `--cm-panel` (آخر رقم = الشفافية، 0.80 حالياً).
- لون التمييز: `--cm-accent`.

## الهوية (تحديث — نفس ألوان الـ MDT)
كل الواجهات (`qb-radialmenu` و `qb-menu` و `qb-input` و `qb-ui`) صارت بنفس تدرّج ألوان تابلت الـ MDT:
تدرّج جرافيت غامق (`#2a2f3b` ← `#11141b` ← أسود)، الأسود هو الغالب، وأزرق الـ MDT (`#3b9dfb`) **بس على الحواف** وبنفس الدرجة الخفيفة في كل مكان (`--cm-line-hot`).
تفاصيل: زوايا زرقاء صغيرة على اللوحات، إضاءة داخلية خفيفة فوق كل بطاقة، الخيارات بشكل بطاقات الـ MDT، مفاتيح الاختصارات بشكل أزرار كيبورد، وخط بعد العنوان الصغير.

## الشكل (آخر تحديث)
أسود بالغالب (شبه مصمت) + **أزرق واضح على الحواف**: إطار أزرق حول اللوحة، زوايا زرقاء أقوى، خط أزرق فوق، والخيار المحدد إطاره أزرق مع شريط جانبي. الأرقام والاختصارات بشكل مربعات كيبورد (مثل زر `E` بالـ DrawText). الألوان في `--cm-*` أعلى ملف الـ CSS (`--cm-edge` = لون الأزرق).

## تخفيف الاستهلاك (آخر تحديث)
خط واحد بدل خطين، بدون ظلال ضبابية على الخانات، بدون أنيميشن شغال على طول، والواجهة `display:none` وهي مقفلة، ومحرّك الصوت ينام بعد القفل.

## جديد (كلها اختيارية، السكربتات القديمة تشتغل مثل ما هي)
- **password**: زر عين يظهر/يخفي الكلام.
- **number**: أزرار `−` و `+`، وتقدر تحدد `min` و `max` و `step`. لو الرقم برا الحد تصير الخانة حمراء وما ينرسل.
  `{ text = 'المبلغ', name = 'amount', type = 'number', min = 1, max = 5000, step = 100 }`
- **textarea** (نوع جديد): نص طويل بأكثر من سطر. `{ text = 'ملاحظات', name = 'notes', type = 'textarea' }`
- **maxLength** على `text` و `textarea`: حد للحروف + عدّاد. `{ ..., maxLength = 16 }`
