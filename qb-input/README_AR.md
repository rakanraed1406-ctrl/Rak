# qb-input

الـ export نفسه (`exports['qb-input']:ShowInput({...})`) وشكل البيانات اللي ترجع نفسه بالضبط، ما تغيّر شي بالنسبة للسكربتات اللي تستخدمه.

## الشكل
- نافذة وحدة **في نص الشاشة** والشاشة وراها **تسود شوي**.
- فوق: العنوان وزر **✕** للإغلاق. تحت: **Cancel** (نص بس) و **Confirm** (زر معبّى).
- نفس ألوان وتفاصيل الراديال منيو (كحلي غامق + أزرق ملكي)، ولمعة زرقاء خفيفة فوق — المتغيرات `--cm-*` أعلى `html/styles/default.css`.
- `--cm-dim` = قوة السواد ورا النافذة (آخر رقم = الشفافية، 0.45 حالياً).
- الخانات الإجبارية عليها `*` حمراء، ولو فاضية تصير حمراء وما ينرسل الفورم.

## خفيف
بدون أصوات، بدون حركات ثقيلة (بس ظهور بسيط 0.15 ثانية)، بدون blur، والواجهة `display:none` وهي مقفلة.

## التحكم
`Enter` تأكيد · `Tab` الخانة اللي بعدها · `Esc` أو ✕ إغلاق.
