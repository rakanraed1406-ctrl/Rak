# Jinxed Town — Military Logistics (JT-MilitaryArmory 3.5)

متجر للقطاعات (CIA، LSPD، …): ميزانية لكل قطاع، سلة، طلب بتوصيل، **كراج أسطول** للمركبات، واستلام الأغراض بـ qb-target.

## الإيفنتات (اربطها بأي سكربت — interact / qb-target / ox_target)
| الوظيفة | الإيفنت (كلاينت) |
|---|---|
| فتح المتجر | `jt-logistics:open` |
| استلام الأسلحة والأغراض (عند الضابط) | `jt-logistics:supplies` |
| تخزين المركبات (عند الضابط) | `jt-logistics:store` |

**اسم الإيفنت لحاله يكفي**: يفتح أقرب متجر عندك صلاحية له. ولو عندك أكثر من متجر وتبي واحد معين، أرسل اسمه.
```lua
-- interact
options = { { label = 'Military Logistics', event = 'jt-logistics:open' } }
options = { { label = 'Military Logistics', event = 'jt-logistics:open', args = 'cia' } } -- متجر معين

-- qb-target / ox_target
{ type = 'client', event = 'jt-logistics:open', label = 'Military Logistics', shop = 'cia' } -- shop اختياري

-- من أي كود
TriggerEvent('jt-logistics:open')                    -- أقرب متجر
TriggerEvent('jt-logistics:open', 'cia')             -- متجر معين
TriggerClientEvent('jt-logistics:open', src, 'cia')  -- من السيرفر
exports['JT-MilitaryArmory']:Open('cia')
exports['JT-MilitaryArmory']:OpenSupplies('cia')
exports['JT-MilitaryArmory']:OpenStore('cia')
```
مثال interact كامل:
```lua
exports.interact:AddInteraction({
    coords = vec3(-2035.03, 3116.78, 32.81), distance = 4.0, interactDst = 2.0, id = 'logistics_cia',
    options = { { label = 'Military Logistics', event = 'jt-logistics:open' } },
})
exports.interact:AddInteraction({
    coords = vec3(-2031.20, 3121.90, 32.81), distance = 4.0, interactDst = 2.0, id = 'logistics_cia_officer',
    options = {
        { label = 'Receive supplies', event = 'jt-logistics:supplies' },
        { label = 'Store the vehicle', event = 'jt-logistics:store' },
    },
})
```
السيرفر يتحقق من الصلاحية والمسافة كل مرة، فما يهم من وين ينفتح. (فيه بعد بوت `openPed` بـ qb-target لو تبيه.)

## التركيب
1. يحتاج: `qb-core`، `oxmysql`، `qb-target`، `qb-inventory`. (اختياري: `screenshot-basic` لتصوير المركبات.)
2. الجداول تنسوى لحالها أول تشغيل (`jt_logistics_shops / orders / depot`). `logistics.sql` لو تبيها يدوي.
3. عدّل `config.lua`: المتاجر، الصلاحيات، المنتجات، الأماكن. `/logisticscoords` (أدمن) يطبع لك `vector4` بالـ F8.

## كيف يمشي
1. **الفتح**: الشاشة تنفتح بالنص (مو كامل الشاشة) → شعار وزارة الداخلية → شريط تحميل 3 ثواني مع **JINXED TOWN** → الشعار ينتقل فوق يسار صغير → المتجر يطلع والكروت وحدة ورا الثانية.
2. **المتجر**: الميزانية فوق، شارة القطاع فوق يمين (CIA)، تبويبات (مدرعات، هليكوبترات، طائرات، أسلحة، أغراض)، وكل منتج له صورة وسعر وستوك.
3. **السلة**: تضيف أكثر من منتج وتعدل الكميات وتشوف الميزانية بعد الطلب → **PLACE ORDER**.
4. **التوصيل**: الطلب ياخذ `deliveryMinutes` (30 دقيقة). تشوف الطلبات اللي بالطريق مع عداد بزر **ORDERS**.
5. **الكراج (الأسطول)** — لما يوصل الطلب:
   - مركبة العرض (`display`) تطلع بمكانها **بس لما يكون فيه وحدة بالكراج**: وحدة لكل نوع، مقفلة ما تنركب. تطلّع آخر وحدة → العرض يختفي، ترجّعها للكراج → يرجع العرض.
   - **الإطلاع**: ناظرها بـ qb-target → **Garage — اسم المركبة** → تشوف `IN GARAGE` (كم موجود) و `OUT` (كم طالع) → تختار كم تطلع (طالب 3 ليزر؟ تطلع 1 أو 2 أو 3). كل وحدة تطلع بمكان فاضي من `spawnPoints` والمفاتيح والبنزين معك.
   - **الإرجاع (التخزين)**: سوق المركبة لين **ضابط الإمداد** (`itemPed`) ووقفها جنبه (ضمن `storeRadius` = 30 متر) → ناظر الضابط بـ qb-target → **Store the vehicle** → تطلع لك قائمة بكل مركبات الأسطول الواقفة حوله (اللوحة، المسافة، حالة المحرك %) → تختار وحدة أو أكثر → **STORE** → ترجع للكراج وتقدر تطلعها مرة ثانية.
     - **أي مركبة من موديلات المتجر** (اللي تنشرى منه) وتكون قريبة من الضابط تنخزن وتنضاف للكراج، حتى لو ما طلعت من الكراج (`Config.Fleet.StoreAnyOfModel = true`). السيارات الشخصية المملوكة (`player_vehicles`) ما تنخزن. `false` = بس اللي طلعت من الكراج.
     - خيار **Store the vehicle** يطلع دايم (ولو `StoreAnyOfModel = false` يطلع بس لما يكون فيه مركبات طالعة من الكراج).
     - المدمرة (**WRECKED**) ما تنخزن. لو انفجرت وانشالت من الماب تروح من الأسطول (`Config.Fleet.DestroyedAreLost`).
     - ما تقدر تخزن مركبة غيرك سايقها، ولا أي مركبة مو من الأسطول.
     - لو المركبة انشالت من الماب لحالها (ما أحد قريب، ريستارت السيرفر) **ترجع للكراج تلقائي** — ما يضيع شي. (`Config.Fleet.KeepInWorld = true` لو تبيها تبقى مكانها.)
     - ريستارت للسكربت؟ المركبات الطالعة يتعرف عليها من جديد وتقدر تخزنها عادي.
   - **الأسلحة والأغراض**: من نفس الضابط → **Receive supplies** → تختار الكميات → تنضاف لشنطتك (لو ما تتسع يبقى الباقي بالمستودع).
6. **الميزانية**: `budget.daily` تنضاف كل 24 ساعة (مثلاً 500,000)، و **DEPOSIT** يخلي أي أحد معه صلاحية يودع من الكاش أو البنك.
7. **الستوك**: كل منتج له حد (`stock`) يترست كل 24 ساعة؛ لما يخلص يكتب **RESTOCK IN …**.

## الصلاحيات (لكل متجر)
```lua
access = { jobs = { cia = 0 }, gangs = {}, citizenids = { ['ABC123'] = true }, onDuty = false }, -- مين يفتح
permissions = {
    order = { jobs = { cia = 3 } }, -- الطلب من رتبة 3 وفوق (nil = نفس access)
    deposit = nil,                  -- الإيداع لكل اللي يفتحون
    pickup = nil,                   -- الاستلام لكل اللي يفتحون
},
terminal = { coords = vector3(...), distance = 15.0 }, -- اختياري: لازم يكون قريب عشان يطلب / يودع
```

## صور المركبات — كلها نفس الزاوية ونفس الإضاءة
- **`/logisticsphotos`** (أدمن، يحتاج `screenshot-basic`): يصوّر كل مركبة بالمتجر في "استوديو" فوق البحر:
  - **الزاوية**: نفسها للكل ومحسوبة من مقاس المركبة نفسها (`Config.Photo.yaw / pitch / fov`) — الافتراضي ثلاثة أرباع من قدّام وجهتها اليسار، ارتفاع خفيف.
  - **الإضاءة**: المركبة تنلف عشان **الشمس تكون ورا الكاميرا** (الجهة اللي تشوفها منوّرة مو بظلها) + إضاءة ناعمة من جهة الكاميرا (`fill`).
  - **القص بدون بنفسجي**: 4 صور PNG لكل مركبة (معها وبدونها، على خلفيتين لونهم مختلف). الواجهة تحسب كم كل بكسل شفاف بالضبط، فالحواف والزجاج والمراوح تطلع نظيفة **بدون أي لون من الخلفية**.
  - الصور تنحفظ في `html/img/vehicles/` (640×360 شفافة، ~20KB). بعدها سو **ريستارت للسكربت**.
  - `/logisticsphotos lazer` = مركبة وحدة.
- تبي زاوية أو إضاءة ثانية؟ عدّل `Config.Photo` وصوّر مرة ثانية:
  ```lua
  Config.Photo = { yaw = 35.0, pitch = 12.0, fov = 28.0, hour = 12, sun = 180.0, fill = 1.0 }
  -- yaw: 0 = من قدّام، 35 = ثلاثة أرباع يسار، -35 = يمين، 90 = من الجنب
  -- لو طلعت الصور مظلمة: غيّر sun (جرب 0 أو 90 أو 270) أو زيد fill
  ```
- لو مركبة ما لها صورة: يستخدم صورة FiveM الرسمية للمركبات الأصلية، وإذا ما فيه → أيقونة القسم.
- الأسلحة والأغراض: صورها من `qb-inventory` تلقائي.
- **نصيحة**: وقت التصوير خل إعدادات اللعبة على جودة عالية، وطفّي TXAA/TAA لو تقدر (يحرك الحواف بين الصور).

## الأسطول بالكونفق
```lua
Config.Fleet = {
    DestroyedAreLost = true, -- المنفجرة تروح من الأسطول (false = ترجع للكراج)
    StoreAnyOfModel = true,  -- أي مركبة من موديلات المتجر قريبة من الضابط تنخزن (false = بس اللي طلعت من الكراج)
    KeepInWorld = false,     -- true = الطالعة تبقى مكانها حتى لو ما أحد قريب
}
-- لكل متجر:
itemPed = { model = 's_m_y_marine_01', coords = vector4(...), label = 'Receive supplies', storeLabel = 'Store the vehicle' },
storeRadius = 30.0, -- المسافة من الضابط اللي تنقبل فيها المركبة
```

## أوامر الأدمن

## المفاتيح والأنتي تشيت
- **qb-vehiclekeys**: المفتاح ينعطى **من السيرفر** (`Config.Keys` → `exports['qb-vehiclekeys']:GiveKeys`) للي طلّع المركبة بس. فالسكربت يعرف إن المفتاح لك → القفل بـ **L** والموتر يشتغلون، والـ anti-cheat حقه ما يسجلها "محاولة غش" ولا يطرد. ولما تنخزن المركبة (أو ترجع للكراج) ينشال المفتاح.
  - تبي كل القطاع يسوق مركبات الأسطول بدون مفتاح؟ في `qb-vehiclekeys/config.lua`:
    ```lua
    Config.SharedKeys['cia'] = { requireOnduty = false, vehicles = { 'lazer', 'hydra', 'hunter', 'akula', 'rhino', 'apc' } }
    ```
- **البلاك ليست** (مثل `Config.BlacklistedVehs` في qb-smallresources — فيها rhino / lazer / hydra / hunter / akula / savage / apc / halftrack …): هذي اللي تخلي المركبات الأصلية تختفي لما ترسبنها بـ `/car` (الأدون مو فيها). مركبات الأسطول **يرسبنها السيرفر نفسه** (`CreateVehicleServerSetter`) بعد ما يتحقق من الصلاحية والكراج والمسافة، فما تمر على البلاك ليست وتطلع عادي — واللاعبين لسا ما يقدرون يرسبنونها بأنفسهم (لا تشيل شي من البلاك ليست).
  - لازم كل مركبة يكون لها `vtype` صح بالكونفق (`automobile` / `heli` / `plane` …).
- **أنتي تشيت ثاني يحذف المركبات؟** حط له استثناء:
  ```lua
  -- سيرفر (ما ينغش: القائمة بذاكرة السيرفر)
  if exports['JT-MilitaryArmory']:IsFleetVehicle(entity) then return end
  -- كلاينت (مركبات العرض + الأسطول من GlobalState اللي بس السيرفر يكتب فيه)
  if exports['JT-MilitaryArmory']:IsLogisticsVehicle(vehicle) then return end
  ```

## الاستهلاك
- **الكلاينت وقت ما تكون بعيد**: فحص مسافة وحد كل ثانيتين ونص، بدون ما يسوي أي شي ثاني. مركبات العرض والمدنيين يطلعون بس لما تقرب (`DisplayDistance`).
- **وأنت بالقاعدة**: ما يعيد حساب مركبات العرض إلا إذا تحركت كم متر أو تغير الكراج (أو كل 15 ثانية احتياط) — وكل بيانات العرض محسوبة مرة وحدة من البداية.
- **qb-target**: الصلاحية تنحسب مرة وتنحفظ (تتجدد لما تتغير وظيفتك)، بدل ما تنحسب كل فريم وأنت ماسك ALT.
- **الواجهة مقفلة** = `display:none`، ولا فيه أي مؤقت شغال. وهي مفتوحة: مؤقت واحد كل ثانية للعدادات.
- بدون مكتبات (لا jQuery ولا غيره)، الحركات كلها transform / opacity بس، بدون blur.
- **السيرفر**: كل شي بالذاكرة، فحص كل 30 ثانية للتوصيل والميزانية اليومية والأسطول (بس المركبات اللي طلعت من السكربت)، والتوصيل نفسه ينجدول على وقته بالضبط.
- **ضابط الإمداد**: ما فيه أي لوب — قائمة المركبات تنحسب بس لما تضغط Store.

## الحماية
- الأسعار، الستوك، الميزانية، الصلاحيات، والمسافات كلها من السيرفر. الكلاينت يرسل أرقام المنتجات والكميات بس.
- كل الأرقام لازم صحيحة موجبة (بدون سالب، كسور، NaN)، وفيه حد لكل طلب.
- قفل واحد لكل العمليات: طلبين بنفس اللحظة ما يقدرون يصرفون أكثر من الميزانية.
- المركبات يرسبنها السيرفر (ولا مرة الكلاينت)، والأسطول ينحفظ بـ GlobalState (اللاعب ما يقدر يزوّر إن مركبته من الأسطول)، والتخزين يقبل بس مركبات الأسطول اللي السيرفر نفسه طلعها (ما تقدر تخزن أي سيارة وتزيد الكراج)، وتكون فعلاً جنب الضابط، ومو مدمرة، وما أحد ثاني سايقها. كل مركبة تتخزن مرة وحدة بس.
- رفع الصور: أدمن بس + جلسة تصوير + اسم موديل من المتجر + لازم WEBP حقيقي.
- كل الأسماء بالواجهة نص عادي (اسم شخصية فيه كود ما يشتغل).

> ملاحظة: نظام الهنقر القديم (طيارات شخصية في `player_helicopters`) ما عاد مستخدم — صار كل شي للقطاعات.

- **التخزين**: ما تنخزن مركبة فيها لاعب ثاني (راكب أو سايق) ولا مركبة تتحرك — عشان ما أحد يطيح من هليكوبتر بالجو.
- **الرسبنة**: ما تطلع مركبة فوق لاعب واقف على نقطة الرسبنة.
- **اللوحات**: كل مركبة تطلع بلوحة ما يملكها أحد ولا موجودة بالماب (المفاتيح بالـ qb-vehiclekeys حسب اللوحة).
- **حماية من السبام**: طلبات المعلومات (الكراج / التخزين / العرض) عليها مهلة، ما أحد يقدر يغرق السيرفر فيها.
- **الخصوصية**: قائمة الأسطول اللي توصل لكل اللاعبين (GlobalState) ما فيها الـ citizenid.
- **بعد ريستارت**: عدد الكراج + الطالع ما يزيد أبد حتى لو الداتابيس والماب مختلفين.
- **المنفجرة**: لو انفجرت وانشالت بسرعة قبل الفحص تنحسب مفقودة (`DestroyedAreLost`).
- **أوامر الأدمن** تقبل اسم المنتج أو الموديل: `/logisticsfleet cia ah64 3` يوصل لـ `Hunter V2`.
