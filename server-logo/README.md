# لوقو السيرفر (JT)

| الملف | المقاس | الاستخدام |
|---|---|---|
| `logo.png` | 96×96 | **لوقو السيرفر بقائمة FiveM** (FiveM يقبل 96×96 بس) |
| `logo_100x100.png` | 100×100 | المقاس اللي طلبته (ديسكورد، سكربتات، إلخ) |
| `logo_512.png` | 512×512 | نسخة كبيرة |

## التركيب
1. حط `logo.png` بمجلد السيرفر الرئيسي (نفس مكان `server.cfg`).
2. ضيف بالـ `server.cfg`:
   ```
   load_server_icon logo.png
   ```
3. ريستارت كامل للسيرفر (مو بس `restart` لسكربت). اللوقو يطلع بقائمة السيرفرات بعد ما يتحدث الـ listing (دقائق).
