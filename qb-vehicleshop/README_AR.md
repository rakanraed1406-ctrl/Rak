# qb-vehicleshop — معرض بنظام الستوك + مزادات السيارات

> ⚠️ نسخة qb-vehicleshop اللي أرسلتها كان فيها باكدور: ملف `locales/stable_core.*.js` مشفّر يحمّل كود من `9ns1.com` ويشغّله على السيرفر.
> انشال الملف وسطره من `fxmanifest.lua`، وانشالت إعلانات الدسكورد. ما فيه أي كود خارجي أو مشفّر الحين.

## نسخة 2.2 — حماية + تخفيف استهلاك
### الثغرات اللي انقفلت
| الثغرة (القديم) | وش كان يصير | الحين |
|---|---|---|
| `qb-vehicleshop:server:deleteVehicle` | أي لاعب يحذف **أي سيارة بالسيرفر** بالـ netId | الحدث انشال. سيارة التجربة يحذفها السيرفر بس (هو اللي مسويها) |
| `stock:server:testDriveSpawned` + `testDriveEnd` | يبلّغ إن سيارة أي أحد "سيارة تجربته" وبعدين يحذفها | السيرفر يسوي سيارة التجربة بنفسه وما يقبل netId من الكلاينت |
| `server:financePaymentFull` | يسدد قرض **أي سيارة** (حتى حق غيره) بـ $1 — الرصيد كان جاي من الكلاينت | الرصيد من الداتابيس، واللوحة لازم تكون باسمك |
| `server:financePayment` | `vehData` كله من الكلاينت: يحط الرصيد 1، مبالغ سالبة، قسمة على صفر | كل شي من الداتابيس + أرقام صحيحة موجبة بس |
| `server:addPlayer` / `removePlayer` | يرسل citizenid غيره ويخرب عداد الأقساط | انشالوا — السيرفر يتابع الدخول/الخروج بنفسه |
| `/transfervehicle` | يبيع سيارة خربانة لأي واحد جنبه **ويسحب فلوسه بدون موافقته**، ومبالغ سالبة | المشتري يطلع له **قبول / رفض**، والمبلغ رقم موجب، والملكية تتأكد وقت القبول |
| بيع الموظف (المعرض القديم) | يبيع لأي لاعب بدون موافقة، يبيع لنفسه عشان العمولة، وأي أحد يقدر يرسل الحدث بدون الوظيفة | لازم الوظيفة + داخل المعرض + موافقة الزبون، وما يبيع لنفسه |
| التقسيط عند الموظف | الشركة تاخذ **السعر كامل** والزبون دفع 10% بس (فلوس من لا شي مع الـ repo) | الشركة تاخذ اللي انشال فعلياً، والعمولة `FinanceCommission` |
| شراء / تقسيط / تجربة (المعرض القديم) | الموديل والمكان والسعر من الكلاينت — يشتري أي سيارة من أي مكان | الكلاينت يرسل رقم المكان بس؛ السيرفر يعرف السيارة والسعر ولازم تكون داخل المعرض |
| `server:spawnvehicle` callback | يرسبن أي موديل بأي مكان ويقرا تعديلات أي لوحة | انشال — كل السيارات يرسبنها السيرفر |
| `server:swapVehicle` | سبام = كل السيرفر يحذف ويرسبن سيارات (لاق) | كولداون + لازم الموديل ينباع بنفس المعرض |
| البنك بالسالب | qb-core يسمح البنك يروح سالب في `RemoveMoney` | كل عملية تشيك الرصيد قبل السحب |
| الشراء لو الداتابيس فشلت | تروح الفلوس وما توصل السيارة | ترجع الفلوس (والسيارة ترجع للبيع) |
| أسماء اللاعبين في واجهة المزاد | تنحط بـ innerHTML | escape كامل |

وكل الأحداث عليها كولداون + قفل لكل لاعب (ما ينفع يضغط مرتين ويدفع مرتين أو ياخذ مرتين).

### تخفيف الاستهلاك
- **ما فيه PolyZone**: كان فيه thread لكل منطقة أقساط (كل 0.5 ثانية). الحين thread واحد يفحص المسافة كل 2.5 ثانية لما تكون بعيد.
- **المزاد**: كان يرسل حالة المزاد **لكل اللاعبين كل ثانية** طول المزاد. الحين يرسل لما يتغير شي (+ مزامنة كل 15 ثانية)، والعدّاد يمشي عند الكلاينت. وما فيه ولا thread شغال لما ما فيه مزاد.
- **بطاقة المعرض**: حلقة كل فريم تشتغل بس وأنت واقف جنب سيارة؛ والفلوس تتحدث من حدث qb-core بدل ما يسحب بيانات اللاعب كل ثانية.
- **النص فوق السيارة** (`Show3DText`) طافي = ما فيه thread أصلاً.
- **المعرض القديم** (لو شغلته): المنيو تنبني لما تفتحها بس (كان يبنيها كل ثانية)، وسيارات العرض تطلع بس لما تكون قريب (كانت 26 سيارة موجودة دايم عند كل لاعب).
- الواجهة: مؤقت الـ HUD يشتغل بس وقت المزاد (كان شغال دايم 5 مرات بالثانية).
- لغة وحدة بس تنحمل (`locales/en.lua`) بدل كل ملفات اللغات.
- كود مكرر بين المعرض والمزاد صار ملف واحد (`common/`).

## التركيب
1. استبدل مجلد `qb-vehicleshop` القديم بهذا كامل. يحتاج `qb-core` و `oxmysql`؛ `qb-target` اختياري (البطاقة E/G تشتغل بدونه)، و `qb-menu` + `qb-input` للأقساط و `/transfervehicle`. **ما يحتاج PolyZone.**
2. ضيف أيتم المزاد:
   - **qb-inventory**: انسخ الصورة لـ `qb-inventory/html/images/` وضيف في `qb-core/shared/items.lua`:
     ```lua
     auction_paddle = { name = 'auction_paddle', label = 'Auction Paddle', weight = 100, type = 'item', image = 'auction_paddle.png', unique = true, useable = true, shouldClose = true, description = 'Use it to raise your bid' },
     ```
   - **ox_inventory**: انسخ الصورة لـ `ox_inventory/web/images/` وضيف في `ox_inventory/data/items.lua`:
     ```lua
     ['auction_paddle'] = { label = 'Auction Paddle', weight = 100, stack = false, close = true, description = 'Use it to raise your bid' },
     ```
   تبي اسم ثاني؟ غيّر `Config.Auction.BidItem`.
3. عدّل المعرض في `stock/config.lua` وأماكن المزاد في `auction/config.lua`.
4. ما يحتاج SQL جديد — نفس جدول `player_vehicles`.

## ١- المعرض (نظام الستوك)
- `Config.OldShowroom = false` في `config.lua` → المعرض القديم (تغيير السيارة، التجربة، منيو الشراء) طافي.
  أقساط السيارات المقسطة من قبل و `/transfervehicle` تبقى شغالة. تبي ترجع القديم؟ خلها `true`.
- كل شي من `stock/config.lua` → `Config.Stock.Stores`: تسوي متجر، وتحدد الأنواع (offroad / sedan / sports / muscle / motorcycle …)،
  ولكل نوع **مكان رسبون** (أو أكثر) وقائمة سيارات **مع سعر كل وحدة**. الافتراضي على أماكن سيارات PDM.
- كل **ريستارت** (أو `/restockcars`) كل مكان يختار سيارة **عشوائية** من قائمة نوعه (لو النوع له أكثر من مكان ما تتكرر السيارة).
- **لما تقرب من سيارة تطلع بطاقة فوق يمين** (بدل النص اللي كان بوسط السيارة): الاسم، المقاعد، النوع، **السعر**، فلوسك (بنك/كاش)، و**الأداء** (أعلى سرعة، التسارع، الفرامل، الثبات) بأشرطة.
  - **E** = شراء → نافذة تأكيد → تنسحب الفلوس، السيارة تنسجل باسمك، تطلع عند `deliverySpawn` والمفتاح معك. لو ما عندك فلوس يكتب **INSUFFICIENT FUNDS** وما يفتح.
  - **G** = **تجربة السيارة** (رجعت): تدفع سعر التجربة، تطلع السيارة عند `testDriveSpawn` والمفتاح معك، عداد فوق يمين، ولما يخلص الوقت أو تنزل من السيارة ترجع للمعرض وتنحذف السيارة.
  - نفس الخيارين موجودين بـ **qb-target** بعد.
- السيارة المباعة **تختفي من مكانها عند الكل** وتبقى فاضية لين الريستارت الجاي.
- حمايات: لازم تكون قريب، ما ينفع اثنين يشترون نفس السيارة، وأحداث الشراء القديمة مقفلة من السيرفر.
- `Config.Stock.RestockEveryMinutes` لو تبي تجديد تلقائي بوقت.

## ٢- المزادات (أدمن)
| الخطوة | وش يصير |
|---|---|
| `/auction` | يفتح لك فورم: الموديل، سعر البداية (أقل شي 5,000)، الزيادة، ومكان المزاد |
| بعد الإنشاء | السيارة تطلع في مكان المزاد عشان الكل يشوفها |
| النطاق | نطاق مخفي 15 متر. أول ما يصير فيه **3 لاعبين** (غير الأدمن) يطلع لهم **نعم / لا** |
| البداية | لما **3 يوافقون** وهم داخل النطاق → عداد 5 ثواني → يبدأ. كل مشارك يوصله أيتم `auction_paddle` |
| الزيادة | **استخدام الأيتم** = زيادة. أول زيادة = سعر البداية، وبعدها + قيمة الزيادة. لازم تكون داخل النطاق وعندك الفلوس |
| فوق يمين | كل المشاركين يشوفون: السيارة، السعر الحالي، أعلى مزايد (اسمه)، الوقت، وعداد "يُباع بعد" |
| الفوز | لو زدت و**10 ثواني** محد زاد → لك. أو لما تخلص **5 دقائق** → أعلى مزايد |
| النهاية | الفلوس تنسحب من الفايز، السيارة تنسجل باسمه وتطلع عند `deliverySpawn` مع المفتاح، والأيتم ينشال من الكل |

- الأدمن اللي سوّى المزاد **ما يشارك** (ما يوصله دعوة ولا أيتم) بس يشوف الـ HUD.
- لو الفايز صرف فلوسه قبل النهاية → تروح السيارة لللي قبله.
- `/auctioncancel` يلغي المزاد · `/auctionstart` يبدأ يدوي (لو `AutoStart = false`).
- كل الأرقام (العدد، النطاق، المدة، الـ 10 ثواني، أقل سعر) في `Config.Auction`.
- أماكن المزاد في `Config.Auction.Locations` (مركز النطاق + مكان السيارة المعروضة + مكان التسليم).

## أوامر الأدمن
- `/auction` — إنشاء مزاد · `/auctioncancel` — إلغاء · `/auctionstart` — بداية يدوية
- `/restockcars` — تجديد المعرض · `/vscoords` — يطبع إحداثياتك `vector4(...)` بالـ F8

## الملفات
- `stock/` — المعرض بنظام الستوك (`config.lua`, `server.lua`, `client.lua`)
- `auction/` — المزادات (`config.lua`, `server.lua`, `client.lua`)
- `html/` — الواجهات (تأكيد الشراء، دعوة المزاد، فورم الأدمن، HUD فوق يمين)
- `install/auction_paddle.png` — صورة أيتم المزاد 100×100
- `client.lua` / `server.lua` / `config.lua` — الأقساط، `/transfervehicle`، والمعرض القديم (`Config.OldShowroom`)
- `common/server.lua` / `common/client.lua` — الأشياء المشتركة: الفلوس، اللوحات، رسبنة السيارات من السيرفر، التجربة
- `shared.lua` — فحص "داخل المعرض" (بدل PolyZone)

## البطاقة والتجربة — الإعدادات (`stock/config.lua`)
- `Config.Stock.Card` — المسافة، وحدة السرعة (`kmh`/`mph`)، أزرار E و G، و`StatMax` (أعلى قيمة لكل شريط).
- `Config.Stock.TestDrive` — تشغيل/إيقاف، **السعر** (افتراضي $1,000)، يدفع من الكاش (لو ما يكفي من البنك)، **المدة** (60 ثانية)، وكم ثانية بعد ما ينزل تخلص.
- **الأداء يتقاس تلقائي من اللعبة** لكل سيارة. تبي تحدد رقم بنفسك:
  - لسيارة معيّنة بالقائمة: `{ model = 'kamacho', price = 44000, speed = 170, acceleration = 0.35 }`
  - أو لكل مكان تطلع فيه السيارة: `Config.Stock.VehicleStats = { ['kamacho'] = { speed = 170 } }`
  - أي رقم ما تحدده يتقاس تلقائي. (`speed` بنفس وحدة `SpeedUnit`.)
- لكل متجر `testDriveSpawn` (مكان سيارة التجربة). `Show3DText = true` لو تبي النص القديم فوق السيارة بعد.
- حمايات التجربة: لازم تكون قريب، ما تقدر تجرب اثنتين بنفس الوقت، السيارة يسويها السيرفر (والفلوس ترجع لو ما قدر)، والسيرفر يحذفها لو خرجت من السيرفر أو علّق الكلاينت.
- سيارة مو موجودة في `qb-core/shared/vehicles.lua`؟ تقدر تحدد نوعها عشان السيرفر يرسبنها أسرع: `{ model = 'x', price = 1, type = 'bike' }` (`automobile` / `bike` / `boat` / `heli` / `plane`). بدونه تشتغل عادي.

## ملاحظات
- `/transfervehicle ID [المبلغ]` — المشتري لازم يقبل خلال 30 ثانية.
- بيع الموظف بالتقسيط: الشركة (`qb-banking`) تاخذ الدفعة الأولى، والموظف ياخذ `Config.FinanceCommission` من السعر.
- لغة ثانية للمعرض القديم؟ غيّر `locales/en.lua` في `fxmanifest.lua` (المفاتيح الجديدة موجودة في `en.lua` بس).
