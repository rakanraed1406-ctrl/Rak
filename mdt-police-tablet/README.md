# Police MDT Tablet — v5.0.0

## هيكلة الملفات
`config.lua` + `fxmanifest.lua` + `server/*.lua` (15 ملف) + `client/*.lua` (14 ملف) + `html/` + `sql/install.sql`.
كل ملف مستقل بموضوعه — عدل الملف اللي يخص الشي اللي تبيه بس.

## أهم التحديثات بهذا الإصدار
1. **تقسيم الكود لملفات متعددة** بدل client.lua/server.lua الضخمين.
2. **لوق ديسكورد** بدال /mdtlog (اللي انشال بالكامل): `Config.DiscordWebhook`. يرسل بس الأحداث المهمة (توظيف/فصل/ترقية/تعليق/Code99/تنبيهات) — فتح/قفل التابلت ما يترسل أبدًا.
3. **الديسباتش: sk1-hub فقط** — كل تنبيه يمر عبر `exports['sk1-hub']:CreateDispatchCall('police', {...})`. غيّر `Config.DispatchResource` لو اسم المجلد مختلف عندك.
4. **تطبيق Dispatch جديد**: مستوى تنبيه القسم (بوس)، بلاغ طوارئ (بوس)، تنبيه لكل الوحدات (أي ضابط، كولداون 20 ثانية).
5. **تطبيق Most Wanted جديد**: Top 10 بالضبط، الإضافة/الحذف للقيادة (رتبة 9+) فقط، ترتيب تلقائي حسب الخطورة.
6. **Suspend**: تعليق وصول ضابط للتابلت مؤقتًا (قيادة فقط)، بدون مساس بوظيفته.
7. **تسجيل دخول/خروج**: استخدام الأيتم وأنت خارج الدوام يسجل دخولك تلقائيًا؛ "Clock Out" بالداشبورد يسجل خروجك ويقفل التابلت.
8. **الإيموشن**: `e tablet` (بدل tablet2)، ينشال تلقائيًا بكل حالات القفل.
9. **إصلاح الخريطة**: تحميل كامل بدون قص (Contain مربع) + منع السحب لأبعد من حدود الخريطة + دبابيس تكتيكية مشتركة حية.
10. **راديو**: زر Best-effort بالداشبورد (`Config.RadioResource`) — أرسل ملفات راديو محددة لو تبي ربط أدق.

## التركيب
1. ضيف أيتم `mdt` بـ `qb-core/shared/items.lua`.
2. ثبّت `sk1-hub` و`qb-bodycam`، وتأكد `Config.DispatchResource`/`Config.BodycamResource` يطابقون أسماء المجلدات.
3. حط رابط `Config.DiscordWebhook` (اختياري).
4. شغّل `sql/install.sql` أو خل السيرفر ينشئ الجداول تلقائيًا.
5. `/mdt` وأنت شرطي.
