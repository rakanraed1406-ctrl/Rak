# Police MDT Tablet — v8.0.0 (Hub + Dispatch مدموجين)

سكربت الـ HUB (sk1-hub / JT-Hub) صار **جزء من التابلت نفسه**. ما تحتاج sk1-hub بعد الحين.

## ⚠️ قبل التشغيل
1. **شيل `sk1-hub` من server.cfg** (أو احذف مجلده) — الأوامر `/911` والإكسبورت صارت داخل التابلت، ولو خليته شغال بيصير تكرار.
2. السكربتات الثانية اللي تنادي `exports['sk1-hub']:CreateDispatchCall(...)` تبقى شغالة بدون أي تعديل (`Config.Dispatch.Sk1HubCompat = true`).
3. أيتم `mdt` لازم يكون موجود — الصورة جاهزة بـ `install/mdt.png` (100×100 خلفية شفافة — ونسخة كبيرة 512×512 بـ `install/mdt_512.png`):
   - **qb-inventory**: انسخ الصورة لـ `qb-inventory/html/images/mdt.png` وضيف في `qb-core/shared/items.lua`:
     ```lua
     mdt = { name = 'mdt', label = 'Police MDT', weight = 1000, type = 'item', image = 'mdt.png', unique = true, useable = true, shouldClose = true, description = 'Police Mobile Data Terminal' },
     ```
   - **ox_inventory**: انسخ الصورة لـ `ox_inventory/web/images/mdt.png` وضيف في `ox_inventory/data/items.lua`:
     ```lua
     ['mdt'] = { label = 'Police MDT', weight = 1000, stack = false, close = true, description = 'Police Mobile Data Terminal' },
     ```

## وش الجديد
### 🛡️ تطبيق Command Hub (قائمة الشرطة داخل التابلت)
- **Roster**: كل الضباط المتصلين — الكول ساين، الرتبة، الحالة، الموقع، المركبة، الراديو، وقت الدوام، و 10-99 يومض أحمر. بحث + فلتر + زر GPS للوحدة + Bodycam.
- **Operations**: تسجيل دخول/خروج الدوام (Clock In / Out)، تغيير الكول ساين، الحالة (Active / Dispatch / Commander / Break)، وزر **PANIC** (اضغط مطوّل ثانية عشان ما ينضغط بالغلط).
- **Comms**: شات القسم بقنوات (#All-Units / #Tac-1 / #Command) مع أكواد سريعة، والهستوري ينحفظ بالسيرفر.
- بلبات الزملاء على خريطة اللعبة (`Config.Hub.UnitBlips`).
- التابلت الحين **ما يسجل دخولك تلقائي**: تفتحه وأنت خارج الدوام → بس Command Hub / Dashboard / About مفتوحة، وباقي التطبيقات تنفتح بعد ما تسجل دخول. تبي السلوك القديم؟ `Config.Hub.AutoClockIn = true`.

### 📡 تطبيق Dispatch (CAD كامل)
- **3 مستويات أولوية** — كل واحد له لون وصوت:
  | المستوى | اللون | الصوت |
  |---|---|---|
  | سهل `low` | 🔵 أزرق | نغمة هادية (نوتتين) |
  | متوسط `medium` | 🟡 أصفر | 3 بيبات |
  | صعب `high` | 🔴 أحمر | إنذار |
- البلاغات مرتبة تلقائي: الأحمر فوق ← الأصفر ← الأزرق، والأحدث أول.
- Respond (يحط GPS)، Detach، Map (يوريك البلاغ على الخريطة التكتيكية)، History، My calls.
- **الديسباتشر** (اللي ماخذ Dispatch أو Commander من الـ Hub، أو القيادة): يعيّن وحدات (يبين لك مين مشغول ببلاغ ثاني)، يعطي أدوار، يغير الأولوية/الحالة، يحدد Scene Supervisor، القناة، يقفل البلاغ، ويسوي بلاغ جديد (من موقعه أو من الـ Waypoint).
- **Command**: مستوى التنبيه (Code Green/Yellow/Red)، بث طوارئ، تنبيه كل الوحدات.
- **Sound & Alerts**: كتم كامل، مستوى الصوت، تشغيل/إيقاف الصوت والإشعار لكل مستوى لحاله، زر تجربة، ومكان الإشعار على الشاشة. الإعدادات تنحفظ لكل لاعب.

### 🔔 الإشعارات والتابلت مسكّر
- إذا التابلت **بالانفنتوري** وأنت على الدوام → توصلك الإشعارات على الشاشة حتى لو التابلت مسكّر (بدون فوكس).
- `G` = Respond · `DELETE` = تجاهل · `/mdtmute` = كتم سريع · `/panic` = بانيك. كلها تتغير من إعدادات GTA → Key Bindings → FiveM.
- لو التابلت مفتوح يطلع الإشعار كبانر داخل الشاشة فيه Respond / View.
- 🔔 بشريط الحالة = كتم سريع، و📡 = عدد البلاغات الفعالة.

### 🗺️ الخريطة
- **الـ Label حق الـ Pin صار داخل الـ NUI** (كان `prompt()` يفتح نافذة برا اللعبة). الحين نافذة داخل التابلت فيها الاسم + اختيار لون.
- الضغط على الـ Pin يعطيك GPS أو حذف. البلاغات تطلع على الخريطة بلون أولويتها.
- كل الـ `prompt()` / حذف ضابط / تعليق صارت نوافذ داخل التابلت.

## 🚨 البلاغات التلقائية (مثل cd_dispatch — مكتوبة من الصفر داخل التابلت)
تطلع للشرطة في تطبيق Dispatch وبالإشعارات بنفس الألوان والأصوات. الإعدادات في `Config.Alerts`.

| البلاغ | الكود | اللون | وش فيه |
|---|---|---|---|
| إطلاق نار | `10-11` | 🔴 | نوع السلاح، جنس المشتبه، الشارع، الاتجاه |
| إطلاق نار من سيارة | `10-60` | 🔴 | السيارة + لونها + اللوحة + اتجاهها |
| كارجاك (سحب سواق) | `10-35` | 🟡 | السيارة + اللون + اللوحة + جنس المشتبه + الاتجاه |
| سرقة سيارة مقفلة | `10-16` | 🟡 | نفس اللي فوق |
| رادار السرعة (طافي افتراضيًا) | `SPEEDING` | 🔵 | السرعة والحد + غرامة تنسحب من اللاعب |

- الشرطة والإسعاف وهم على الدوام ما يطلّعون بلاغات (`IgnoreJobs`).
- إطلاق النار: أسلحة مستثناة (فلير، تيزر…)، الكاتم ما يطلّع بلاغ، وأماكن مستثناة (ميدان الرماية).
- سرقة السيارة: لو معك مفتاحها (qb-vehiclekeys) ما يعتبر سرقة.
- رادار السرعة: فعّله بـ `SpeedTrap.enabled = true`، حدد الأماكن والحد والغرامة. `checkOwner` = يغرّم بس صاحب السيارة.
- كل بلاغ له كولداون، والموقع يتاخذ من السيرفر (ما ينفع أحد يزوّر مكانه).
- بلب الوحدة يومض لما السيارين شغال (`FlashBlipOnSiren`).
- صوت البانيك يسمعه أي أحد قريب (`PanicSoundRadius`).

### أوامر المواطنين
- `/911 رسالة` — بلاغ عادي (اسم + رقم المتصل).
- `/911a رسالة` — **بلاغ مجهول**: الشرطة ما تشوف اسمه ولا رقمه ولا الـ ID حقه.
- `/reply C1001 رسالة` — الشرطي يرد على المتصل (حتى لو مجهول). رقم البلاغ يطلع في تفاصيله بالتابلت.

## الإعدادات (config.lua)
- `Config.Dispatch` — الأوامر، شرط الأيتم/الدوام للإشعارات، مدة الإشعار، الأزرار، **`CodePriority`** (تحدد لون كل كود)، الأدوار، الأصوات المخصصة.
- `Config.Hub` — AutoClockIn، قنوات الشات، البلبات.
- `Config.Alerts` — البلاغات التلقائية (إطلاق نار، سرقة سيارة، رادار السرعة).

## ربط سكربت ثاني (مثال: سكربت سرقة)
أي طريقة من هذي تطلع إشعار للشرطة (اللي على الدوام ومعهم التابلت):

**من الكلاينت** (داخل سكربت السرقة وقت ما يبدأ اللاعب يسرق — الإحداثيات والشارع تنحط تلقائي من مكان اللاعب):
```lua
TriggerEvent('mdt:client:CreateDispatchCall', {
    code = '10-90',
    title = 'Store Robbery',
    priority = 'high',              -- low (أزرق) / medium (أصفر) / high (أحمر)
    description = 'Silent alarm triggered at the store',
    tags = { { icon = 'fa-gun', label = 'Armed suspect', isWeapon = true } }
})
```

**من السيرفر:**
```lua
TriggerEvent('mdt:server:CreateDispatchCall', {
    code = '10-90', title = 'Bank Robbery', priority = 'high',
    street = 'Fleeca — Legion Square',
    coords = vector3(147.0, -1045.0, 29.3),
    description = 'Vault alarm'
})
```

**أو بالإكسبورت** (نفس الشي، سيرفر أو كلاينت):
```lua
exports['mdt-police-tablet']:CreateDispatchCall('police', { code = '10-90', title = 'Store Robbery', priority = 'high' })
exports['sk1-hub']:CreateDispatchCall('police', { ... }) -- السكربتات القديمة تشتغل بدون تعديل
```
- الأولوية تقبل كمان `HIGH/NORMAL/LOW` أو `1/2/3`. ولو الكود موجود بـ `Config.Dispatch.CodePriority` هو اللي يحدد اللون.
- بلاغات الكلاينت فيها حد: بلاغ واحد كل 3 ثواني لكل لاعب (ضد السبام).
- سكربتات تستخدم `ps-dispatch` / `cd_dispatch` / `qb-dispatch` events تشتغل تلقائي.

## مدة الإشعار
الإشعار **ما يبقى طول الوقت**: يدخل بأنيميشن، يبقى، ويطلع بأنيميشن لحاله:
سهل 🔵 10 ثواني · متوسط 🟡 15 ثانية · صعب 🔴 20 ثانية — تتغير من `Config.Dispatch.ToastDuration`.
الأحمر يومض أول ما يدخل. تقدر تسكّره قبل بـ `DELETE` أو ترد بـ `G`.

- `html/js/dialog.js` (النوافذ داخل التابلت) · `notify.js` (الإشعارات والأصوات) · `hub.js` · `dispatch.js` · `html/css/hub.css`.
