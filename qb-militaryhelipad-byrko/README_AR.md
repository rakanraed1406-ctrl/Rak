# Jinxed Town — Military Logistics (qb-militaryhelipad-byrko 3.0)

متجر للقطاعات (CIA، LSPD، …): ميزانية لكل قطاع، سلة، طلب بتوصيل، مستودع، واستلام المركبات والأغراض بـ qb-target.

## فتح المتجر (اربطه بأي سكربت — interact مثلاً)
```lua
TriggerEvent('jt-logistics:open', 'cia')            -- من الكلاينت
exports['qb-militaryhelipad-byrko']:Open('cia')       -- أو export
```
مثال interact:
```lua
exports.interact:AddInteraction({
    coords = vec3(-2035.03, 3116.78, 32.81), distance = 4.0, interactDst = 2.0, id = 'logistics_cia',
    options = { { label = 'Military Logistics', action = function() TriggerEvent('jt-logistics:open', 'cia') end } },
})
```
السيرفر يتحقق من الصلاحية كل مرة، فما يهم من وين ينفتح. (فيه بعد بوت `openPed` بـ qb-target لو تبيه.)

## التركيب
1. يحتاج: `qb-core`، `oxmysql`، `qb-target`، `qb-inventory`. (اختياري: `screenshot-basic` لتصوير المركبات.)
2. الجداول تنسوى لحالها أول تشغيل (`jt_logistics_shops / orders / depot`). `logistics.sql` لو تبيها يدوي.
3. عدّل `config.lua`: المتاجر، الصلاحيات، المنتجات، الأماكن. `/logisticscoords` (أدمن) يطبع لك `vector4` بالـ F8.

## كيف يمشي
1. **الفتح**: الشاشة تنفتح بالنص (مو كامل الشاشة) → شعار وزارة الداخلية → شريط تحميل 3 ثواني مع **JINXED TOWN** → الشعار ينتقل فوق يسار صغير → المتجر يطلع والكروت وحدة ورا الثانية.
2. **المتجر**: الميزانية فوق، شارة القطاع فوق يمين (CIA)، تبويبات (مدرعات، هليكوبترات، طائرات، أسلحة، أغراض)، وكل منتج له صورة وسعر وستوك.
3. **السلة**: تضيف أكثر من منتج وتعدل الكميات وتشوف الميزانية بعد الطلب → **PLACE ORDER**.
4. **التوصيل**: الطلب ياخذ `deliveryMinutes` (30 دقيقة). تشوف الطلبات اللي بالطريق مع عداد بزر **ORDERS**.
5. **المستودع** (لما يوصل):
   - **المركبات**: تطلع مركبة عرض وحدة بس لكل نوع بمكانها (`display`) — مقفلة ما تنركب، وتختفي لما يخلص المخزون. ناظرها بـ qb-target → **Take out** → تختار كم وحدة (لو طالب 3 ليزر تختار 1 أو 2 أو 3). كل وحدة تطلع بمكان فاضي من `spawnPoints` (أكثر من مكان، وحدة لكل مكان عشان القلتشات) والمفاتيح معك.
   - **الأسلحة والأغراض**: من المدني `itemPed` بـ qb-target → **Receive supplies** → تختار الكميات → تنضاف لشنطتك (لو ما تتسع يبقى الباقي بالمستودع).
   - **إرجاع**: مركبة طلعت من المستودع؟ ناظرها بـ qb-target → **Return to depot** وترجع للمخزون (لازم تكون قريبة من القاعدة وما تكون مدمرة).
6. **الميزانية**: `budget.daily` تنضاف كل 24 ساعة (مثلاً 500,000)، و **DEPOSIT** يخلي أي أحد معه صلاحية يودع من الكاش أو البنك.
7. **الستوك**: كل منتج له حد (`stock`) يترست كل 24 ساعة؛ لما يخلص يكتب **RESTOCK IN …**.

## الصلاحيات (لكل متجر)
```lua
access = { jobs = { cia = 0 }, gangs = {}, citizenids = { ['ABC123'] = true }, onDuty = false }, -- مين يفتح
permissions = {
    order = { jobs = { cia = 3 } }, -- الطلب من رتبة 3 وفوق (nil = نفس access)
    deposit = nil,                  -- الإيداع لكل اللي يفتحون
    pickup = nil,                   -- الاستلام لكل اللي يفتحون
},
terminal = { coords = vector3(...), distance = 15.0 }, -- اختياري: لازم يكون قريب عشان يطلب / يودع
```

## صور المركبات — كلها نفس الزاوية ونفس المكان ونفس الإضاءة
- **`/logisticsphotos`** (أدمن، يحتاج `screenshot-basic`): السكربت يصوّر كل مركبة بالمتجر **مرة وحدة**:
  تطلع المركبة في "استوديو" فوق البحر، الكاميرا تنحسب من **مقاس المركبة نفسها** (نفس الزاوية الأمامية الجانبية للكل، نفس البُعد بالنسبة لحجمها)، الوقت الظهر والجو صافي، خلفية ثابتة.
  تنأخذ صورتين (مع المركبة وبدونها)، والواجهة تقص المركبة **بدون خلفية** وتحطها بنص إطار 640×360 بنفس الهوامش → كل الصور متناسقة، حتى المركبات المضافة (addon).
  الصور تنحفظ في `html/img/vehicles/` (~10KB للصورة). بعدها سو **ريستارت للسكربت** عشان توصل للاعبين.
  `/logisticsphotos lazer` = مركبة وحدة.
- لو مركبة ما لها صورة: يستخدم صورة FiveM الرسمية للمركبات الأصلية (نفس الزاوية للكل)، وإذا ما فيه → أيقونة القسم.
- الأسلحة والأغراض: صورها من `qb-inventory` تلقائي.

## أوامر الأدمن
- `/logisticsbalance cia 5000000` — تحدد ميزانية قطاع
- `/logisticsphotos [model]` — تصوير المركبات
- `/logisticscoords` — يطبع إحداثياتك

## الاستهلاك
- **الكلاينت وقت ما تكون بعيد**: فحص مسافة وحد كل ثانيتين. مركبات العرض والمدنيين يطلعون بس لما تقرب (`DisplayDistance`).
- **الواجهة مقفلة** = `display:none`، ولا فيه أي مؤقت شغال. وهي مفتوحة: مؤقت واحد كل ثانية للعدادات.
- بدون مكتبات (لا jQuery ولا غيره)، الحركات كلها transform / opacity بس، بدون blur.
- **السيرفر**: كل شي بالذاكرة، فحص كل 30 ثانية للتوصيل والميزانية اليومية، والتوصيل نفسه ينجدول على وقته بالضبط.

## الحماية
- الأسعار، الستوك، الميزانية، الصلاحيات، والمسافات كلها من السيرفر. الكلاينت يرسل أرقام المنتجات والكميات بس.
- كل الأرقام لازم صحيحة موجبة (بدون سالب، كسور، NaN)، وفيه حد لكل طلب.
- قفل واحد لكل العمليات: طلبين بنفس اللحظة ما يقدرون يصرفون أكثر من الميزانية.
- المركبات يرسبنها السيرفر، و"الإرجاع" يقبل بس مركبات طلعت من المستودع (ما تقدر ترجع أي سيارة وتزيد المخزون).
- رفع الصور: أدمن بس + جلسة تصوير + اسم موديل من المتجر + لازم WEBP حقيقي.
- كل الأسماء بالواجهة نص عادي (اسم شخصية فيه كود ما يشتغل).

> ملاحظة: نظام الهنقر القديم (طيارات شخصية في `player_helicopters`) ما عاد مستخدم — صار كل شي للقطاعات.
